# How to run analysis
## Setup python enviornment
- Running in WSL need to first run:
```
sudo apt update
sudo apt install python3-venv
```
- Next run
```
sudo apt install python3.12-venv
```
- Then start virtual enviornment
```
python3 -m venv venv
source venv/bin/activate
```
- Install all python packages as needed when running the script
- To end virtual enviornment
```
deactivate
```
